# V15：站立修复与估计器实验（2026-09-08）

## 结论与可用边界

- `rs01_omni_v15_stand_phase`：保留 V14 全部执行器、奖励、估计器，仅 gait_enable=0 时冻结相位；踏步/移动恢复原时钟，不重置相位。A6850 可直接使用，不要求为了站立修复重新训练。
- `rs01_omni_v15_support`：额外启用实验性重力感知支撑估计器。**未通过 MuJoCo 验收，不建议长训或上真机**。保留代码用于复现，不替换 V14 或站立修复任务。
- 这次没有修改真实部署代码，没有启动长训练，没有推送仓库。

## 改动范围

训练与 MuJoCo 共用 `rs01_support_odometry.py` 的 Torch 实现（GPU 批处理 / CPU 单实例），只用 q、dq、IMU 角速度和重力方向；不使用仿真接触、根速度或指令速度来构造估计值。几何高度与垂直运动使用重力方向，速度估计不硬限定两只对角支撑足。置信度仍是启发式指标，不是经过校准的接触概率，也无法保证无滑移。

真实 RS01 已辨识增益、延迟、FOPDT、摩擦、Kp/Kd、扭矩限幅、目标速度/加速度限制、2.5ms反馈/5ms响应/20ms策略时钟全部不变。奖励和指令范围未改，没有新增奖励冲突。

仅冻结相位的A6850：四相位站立均跑满30秒，但同样55秒切换序列只有1/4完成，其他三次在51.86/21.08/16.32秒终止。相位修复不能被表述为整机动作切换已修好；后退轨迹与V14保持一致。

PhysX A7000：24指令×4环境×30秒，seed20260919，共3次重置；站立、踏步、后退-0.2各0次重置。与MuJoCo差异说明只看训练后端不能验收。两个后端初态分布不同，不能将重置数与MuJoCo完成数当作严格配对统计。

后退 p025 的1.0–1.5秒窗口：原估计 vy=+0.1449，实际=-0.0257m/s，置信度0.8876；新估计器+A6850该窗口估计+0.0066，实际+0.0063m/s。闭环轨迹已改变，这只是局部表现改善，并不证明全部估计误差已解决。

初次额外测试使用2秒静态settle，结果站立3/4、后退2/4；它不与冷启动基线混比，也提示初始状态鲁棒性仍不足。
