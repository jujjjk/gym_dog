## 代码与配置

新建 `rs01_omni_v26_config.py` / `rs01_omni_v26_env.py`，任务 `rs01_omni_v26_inward3`、`inward5`。
新建测试，扩展原audit/play任务白名单。没有改旧V20/V25环境行为、没有新增/改奖励权重。
两组均继承V25 A（方向步频floor2.0Hz），只比较omni内收目标3°/5°。
注意：下述zero-shot、100轮短训及nominal/fast/switch_{3,5}日志均属于最初的**全周期压缩试验**，
这版因跟踪和滑移问题被否决，不作为当前代码的可部署模型。
当前代码已改为**相位条件化**：3°/5°是摆腿末端与触地边界，承重中段放回8°。
相位权重连续：摆动前半不收紧，后半smoothstep收紧，落地后在原双支撑交接段smoothstep释放；
相位跨0/1时连续，不靠仿真接触truth驱动控制映射。既不恢复全范围内收，也不全周期压紧承重腿。
直行与踏步仍完全保留旧8°目标映射，外展目标及其他8关节完全不变。
轻微横移/转向指令时在旧8°与新3°/5°之间连续插值。

这不是把物理髋关节状态硬钳住，而是压缩actor可请求的内收目标幅度：
`default + scale*clipped_action → 新映射一次 → 原限速/加速度 → 延迟/响应 → host guard → motor PD/真实力矩限制`。
旧V20映射不再调用，避免双重压缩；左右动作不镜像，允许补偿性不对称。
目标角限制不是对真实足端宽度的数学保证，更不等于动态抗推稳定保证。
