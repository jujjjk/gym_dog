# V24：实际支撑脚落脚区域

## 修改与边界

基线保留 V23 A26500：
`logs/rs01_omni_v23_balance18/Oct03_14-49-50_v23_gpu0_seed16_20261003_144947/model_26500.pt`。

旧脚对宽度同时计入摆动脚，也允许一脚内收、另一脚外展抵消。
V24 在现有 placement 项内部替换 width cost，不叠加旧宽度奖励、不新增 reward scale。
仅对现有接触检测器认定的支撑脚计算，触地瞬间同一项权重加倍。
横向位置在重力对齐的 yaw 坐标系内，相对机身根位置计算；左右按自身一侧取正。
不是髋关节角硬锁，不要求左右等力、等步幅；原直行条件性相位协调保持。

- A：每只支撑脚距中线软下界 10cm；B：11cm；共同软上界 22cm。
- 这是工程先验，不是实测安全边界。上界防止无限外展，内外侧采用连续 Huber cost。
- 只接触时计罚；原非法接触、腾空与对角支撑目标不变。
- 真实 RS01 非理想执行器、限速限矩、PD、61D sensor actor、command/reward 对齐不变。
- V21 提取默认宽度计算 hook，旧 V21/V23 数学行为不变；单测覆盖回归。
- 足端横向区域不等于动态支撑裕度，也不能保证质心位于稳定支撑区。

## 分阶段，不一次堆扰动

第一阶段 A/B 仅学习落脚区域。固定学习率及优化器重置策略继承 V23。
第二阶段必须等姿态、速度和落脚区域验收后再设计扰动训练，当前没有自动启用。

新增 `audit_rs01_v24_support.py` 独立诊断：前进、横移、后退组合 × 8 条件 × 4 环境。
条件为无扰动、±X/±Y 外力、Trunk 质量 +0.5kg、Trunk COM 横向 ±1cm，分别测试，不叠加。
第 3 秒在 Trunk COM 施加 ENV_SPACE 10N，持续 0.20s；每个 physics step 调用外力接口，
累计施加冲量约 ±2Ns。不是旧代码直接改机身速度。复位会取消剩余外力并保留已施加冲量。
质量/COM 是创建时修改，读取 PhysX actor 属性核验；不等于精确附加负载惯量，也不是中途突加负载。
每组传感器噪声独立，不将组间差异当作严格配对因果实验；当前未扫描不同支撑交接相位。

## 已验证基线

`../artifacts/rs01_v24/baseline_probe.json`：seed20261003，96 环境 ×8s，零复位，finite，actor/reward 对齐。
统计忽略前 2 秒；以下是接触脚样本中距中线小于 10cm 的比例，不是倒地率：

| 无扰动指令 vx/vy/wz | 内侧样本 | 触地内侧样本 | roll RMS |
|---|---:|---:|---:|
| 0.2 / 0 / 0 | 0.0% | 0.0% | 0.83° |
| 0 / 0.2 / 0 | 30.7% | 18.0% | 3.29° |
| -0.2 / -0.08 / -0.25 | 69.1% | 68.1% | 1.21° |

说明机身 roll 较小不能证明支撑脚区域合理。10N 短脉冲未导致复位，也不能证明更大推力安全。

## 训练与验收

两组 smoke：256 环境、20 轮，从 26500 到 26520。22 项 V21–V24 单测通过。
12 个快速固定动作 ×4 环境 ×12s：A/B 均零复位、finite、actor/reward 对齐；
平均分动作 roll RMS 分别 1.803° / 1.922°，原始 PD 峰值 16.55 / 15.50Nm
（原始需求不是最终施加力矩，仍应检查饱和与 RMS）。
96 环境 ×8s 扰动诊断：A 零复位；B 在横移 +Y 10N 侧推组复位 1 次。
B 只是较宽的训练对照，不能作为部署候选；不能推断加宽必然提升稳定性。
A 无扰动横移/后退组合的内侧比例为 28.7% / 66.5%，比基线略低但远未解决。
B 的内侧率按 11cm 统计，不能与 A 的 10cm 原始比例直接作优劣比较。
直接切换 12 动作，每动作 3s、4 环境，总计 36s：A/B 均零复位且 finite。
短训只验证训练链路与短时运动，不以它替代 A26500、不宣称内收已修复。
