# URDF4 V2 AMP：Isaac Gym 验证（2026-11-13）

结论：V2通过新URDF的Isaac Gym正运动学、名义执行器跟踪和AMP/PPO数值组合验证。没有证明从零AMP训练已经学会该步态，也未完成随机化或实机验收。

## 仓库与物理合同

基线999d952，原有11.md未修改。只新增验证工具、URDF4 AMP特征/数据合同适配器和验证产物，未改动原URDF、V1/V2数据或5400权重。GPU0，seed1，PhysX GPU pipeline；关闭随机化、传感器噪声和推力。自碰撞保持当前URDF4任务设置（关闭）。

使用相同12关节/14N·m motor限幅、40/1 PD、50Hz目标限速和5ms响应更新、40ms延迟、31.9ms时间常数、0.928增益。形状、质量、惯性均来自同一份新URDF。数据与活动URDF SHA256一致。

## 1. 正运动学验证

12动作×51个姿态，共612个样本。零重力、抬高至地面上方、不施加关节力矩，仅用于FK；不将这一步算作动力学。足端最大重建误差：13.89微米，门槛20微米。关节顺序FL/FR/RL/RR、左右轴向及wxyz→xyzw转换一致。

## 2. 自由基座的原执行器跟踪

先重新记录MuJoCo设计控制器的50Hz目标指令，包括2秒静态初始化；再通过Gym原有action缩放/裁剪、目标速度/加速度限制、延迟、一阶响应、PD、电机力矩限幅与摩擦重放。没有直接施加参考扭矩，没有覆写运动中的根位姿或关节状态。各环境仅初始设置一次源姿态、零速度。之后关闭自动复位，首次失败单独标记，不用reset掩盖失稳。

两个执行器使用不同默认站姿，按0.928响应增益做等价命令坐标转换；不改变物理参数或放宽动作范围。源MuJoCo状态记录时刻为子步后2.5ms，因此按实际时刻插值至Gym的20ms末端，避免把一个policy-step错位计为误差。

初测20秒×2环境/动作全部通过；复测60秒×4环境/动作全部通过，共48条60秒轨迹、2880机器人秒。稳态指标剔除最初2秒运动和末端不足插值的一帧。目标速度误差门槛0.05m/s、角速度0.12rad/s；关节RMSE门槛0.10rad、足抬升P95最低20mm、raw峰值17N·m。实际误差远低于关节门槛。

## 3. AMP与PPO组合验证

新增隔离适配器 `unitree_rl_gym/legged_gym/envs/urdf4/amp_reference.py`：检查活动URDF哈希、关节/足顺序、四元数、46维语义和20ms步长。未批准参考仅允许显式validation_only调用；错误URDF会在加载前拒绝。保留原始数据approval标志。

判别器读取形状12×2499×92，条件输入95维；Gym实时46维状态形成有效相邻transition，reward与一次判别器梯度更新有限。另以64环境×24步运行1轮新建actor的PPO+AMP奖励组合更新：PPO损失[0.12307784333825111, 0.06074455752968788]，判别器损失1.328513，均无NaN/Inf。没有加载或覆盖任何旧策略。

捕获终止帧在自动reset之前，跨reset和命令改变的transition排除，不把下一回合首帧当专家转移。批准标志检查与错误URDF拒绝检查均通过。
