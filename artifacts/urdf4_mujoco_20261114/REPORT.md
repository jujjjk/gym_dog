# 第17800轮策略 MuJoCo Sim2Sim 验证

结论：12类动态动作 × 3种子 × 30 s，共36组步态验证通过；额外3组站立仅通过平衡保持，未通过静止站立标准。没有把速度追踪当作当前阶段的步态门槛，也没有生成联合追踪验收通过回执。

## 仓库、物理模型与基线

代码基线 `4cfccdf`，本轮新增 `mujoko/urdf4_amp/`。原训练代码、模型和未相关工作区文件保持不变。本轮没有训练或部署。

仍使用 `unitree_rl_gym/resources/robots/urdf4/urdf/urdf4_rs01.urdf`，SHA256 `528c088ff240916b04dfc98611ae9437b92a31cfafc9a297399632e8d0774b91`。质量11.569864831733414 kg，FL大腿/小腿长度约0.180/0.186 m；CAD惯量和原始碰撞基元保留，关闭自碰撞，与Gym任务一致。MuJoCo XML序列化的惯量/质量保留17位有效数字。显示时仅隐藏碰撞包络，不改变物理。

对照基线为 `artifacts/urdf4_selection_20261114/verify17800/result.json` 的同一模型Gym 30秒结果。模型SHA256：`42845cb95de28a0eb94ad41ff8538673d67f6071e3c7edfb231deb877479d355`。

## 控制、观测与执行器

公开输入51维 × 20帧历史，最新帧在前。输出12关节动作，按关节名映射，不依赖MuJoCo自身关节遍历顺序。输入包含机体角速度、重力、指令、q/dq、上一动作、相位、周期平均偏航误差、航向误差和步态开关。MuJoCo坐标采用wxyz，导出边界不含教师观测。角速度/线速度统一转换到URDF机体坐标系，使用[MuJoCo object velocity API](https://mujoco.readthedocs.io/en/latest/APIreference/APIfunctions.html#mj-objectvelocity)；碰撞掩码遵循[MuJoCo geom规则](https://mujoco.readthedocs.io/en/latest/XMLreference.html#body-geom)。

控制链与Gym一致：20ms策略 → 动作裁剪±2 → 分关节动作缩放0.15/0.25/0.25 → 目标速度上限2/2.6/3.2 rad/s与加速度60/78/96 rad/s² → 40ms延迟 → 每5ms更新31.9ms一阶响应，增益0.928 → Kp40/Kd1 → 电机限幅14 N·m → 0.156 N·m库仑摩擦 → 2.5ms物理步长。6 N·m作为持续负载参考、17 N·m作为峰值验收线，不混同电机实际限幅。

接触参数在验证前固定：摩擦0.8，condim3、solref[0.0065,1]、solimp[0.99,0.999,0.0001,0.5,2]，积分implicitfast。PhysX与MuJoCo接触求解不同，不能声称逐位物理等价。本轮未针对失败片段改质量、PD、动作或接触参数。

## 问题与修改

| 问题 | 修改 | 证据 |

## 数值与运动学检查

- TorchScript→NumPy最大动作误差：4.529953e-06。
- 实际NumPy控制桥对比原Torch限速、延迟、响应、PD/限幅/摩擦1000子步，最大扭矩差：4.82681862e-07 N·m。
- 12参考片段共600个姿态，足端FK最大差：1.48972328e-08 m；机体角速度、重力和线速度数值误差均为0。
- 状态写入只用于独立FK/控制器单元检查；策略物理验证不使用这些写入。

## 动作协议与结果

每个动作种子1/2/3，初始关节±0.02 rad微扰，默认目标落地2 s后完全由学生网络闭环执行30 s；丢弃前3 s统计。无推力、随机化或观测噪声，无基座支撑外力、无参考轨迹注入、无自动重置。

动态动作要求：不跌倒、无腾空、非法支撑占比≤0.1%，真实迈步/对角交替次数达标，对角落地P95差≤40ms，原始扭矩峰值≤17 N·m，限幅占比≤1%，足高P95相对相同Gym策略的逐腿偏差≤10mm。站立额外要求四脚支撑≥95%且足高P95≤5mm。速度误差独立记录，不作为本阶段步态门槛。

## 演示命令

```bash
cd /home/nszb/gym
bash mujoko/urdf4_amp/play_selected.sh --sweep --seconds 10
```

单动作：`bash mujoko/urdf4_amp/play_selected.sh --motion forward_slow`。可选march/forward_slow/forward/backward/left/right/turn_left/turn_right/forward_left/forward_right/arc_left/arc_right/stand。

N下一动作，B上一动作，空格暂停，R重置。鼠标旋转/平移/缩放，默认平移跟随但不锁旋转与缩放。窗口已实际启动检查。换动作会重新初始化并落地2秒，随后运行策略；默认每动作10秒。若跌倒则暂停，按R重新开始。

Python环境为 `/tmp/urdf4_validation_env/bin/python`（MuJoCo3.17.0、NumPy2.2.6），可用环境变量URDF4_MJ_PYTHON指定其他同依赖环境。模型数据仍在本机，干净克隆代码需准备配套导出资源。

## 限制与回滚

这是名义条件Sim2Sim步态验证，不包含连续0–0.6m/s、扰动鲁棒性、长时热安全、实机与精确速度跟踪认证。未改训练模型、URDF或既有控制代码；关闭窗口即可停止，删除新增输出不影响旧模型。全部原始rollout和parity_result.json保留供复核。
