## 5. 问题、证据与修改

| 问题 | 实测证据 | 本次处理 | 验收 |
|---|---|---|---|
| 质量改变后旧状态不再是新模型记录 | URDF hash / 质量变更 | 新场景重新物理执行并保存真实 q/dq、机身与脚状态 | 每帧与源记录精确一致 |

## 6. 文件与格式

- `manifest.json` + 本目录 NPZ：51 段固定命令，每段 2,500 帧。
- `transitions/`：18 段连续变命令，21,000 帧；包括四向/斜向起停、加减速、前进转侧移、前进转转向、转向转前进。
- `gym_verified/`：两种仿真均通过的 59 段，建议 Gym 新任务从这个子集接入。
- `commands/`、`transition_commands/`：原始物理记录和教师命令，用于复现。
- `reference_v3.py` 位于仓库 `tools/urdf4_amp/`：严格校验 URDF/文件 hash，支持变命令、多频率、站立 phase mask 与条件采样。过渡文件保留控制时钟，该适配器给出共同对角时钟的实际接触对齐标签。
- `motions.csv`、`coverage.json`、`dataset_audit.json`、`validation_receipt.json`：逐动作范围、验收、来源与校验。

AMP 状态 46 维：q12 / dq12 / 脚在机身系位置12 / 机身线速度3 / 机身角速度3 / 重力投影3 / 高度1。相邻帧组成92维，再加命令3维得到95维判别器输入。每段最后一帧的 transition_valid=False；不拼接段与段之间的状态。

## 12. 回滚与复现

V3 是独立数据与工具，原V2目录、模型和URDF原始CAD文件未覆盖。每段 source_folder 指向本目录原始记录；模型/脚本hash见验证收据。单段可复现为：

```bash
/tmp/urdf4_validation_env/bin/python tools/urdf4_amp/physical_v3.py \
  --design artifacts/urdf4_amp_design_20261116_v3/plant \
  --spec /home/nszb/gym/artifacts/urdf4_amp_design_20261116_v3/amp_reference_v3/manifest.json \
  --motion forward_p0500_p0000_p0000 --seconds 60 --output /tmp/urdf4_v3_reproduce
```

旧V2对应旧质量；新质量 hash 校验继续生效，不通过关闭校验来复用旧质量状态。

数据zip只含专家NPZ、URDF快照、清单与验收文档；原始物理记录和本机查看依赖本目录的 commands/、transition_commands/ 及仓库mesh。
