# 起步与变速复测 · 2026-11-19

实验任务为 `urdf4_amp_cts_transition`，使用原第 2500 轮模型。起步改为检测姿态、速度和四脚支撑，在至少 0.28 秒后且连续安静 0.12 秒时放行。跨高速门槛需要至少三脚重叠支撑，并参考滤波速度。步频有变化率限制，换速期间延续原相位。高速减速时释放速度 PI 的纵向补偿，高速升档时把正补偿限制为 0.08 m/s。姿态和足接触用于仿真控制门槛。训练奖励、模型权重、RS01 执行器限幅均沿用原设置。

同一策略在无推力条件下执行 0.18 → 0.50 → 0.25 → −0.15 → 0.00 m/s，每段 6 秒。扭矩是所有物理子步的原始 PD 峰值，速度是目标段最后 1 秒的平均值。每种地面两份副本，表中倾角和偏移是最差值。原演示基线的扭矩只在 50 Hz 控制结束时采样，22.31 N·m 是该次测试的峰值下界。
