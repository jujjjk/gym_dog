# 第17800轮模型：扭矩与速度统计

模型 `model_17800.pt`；SHA256 `42845cb95de28a0eb94ad41ff8538673d67f6071e3c7edfb231deb877479d355`，代码 `4cfccdf`。RS01物理模型和控制参数保持不变。

每个动作4环境，种子1，冷启动保持默认关节目标2 s，然后学生策略执行30 s，丢弃前3 s，统计27 s稳态数据。无推力、随机化或观测噪声；52环境涵盖12类动态动作与站立。全部无重置、腾空和非法支撑。

平均扭矩采用每电机绝对值，再对12电机、4环境、时间求平均，不让正负抵消。覆盖全部400 Hz物理子步，每动作每环境10800个子步。原始PD是限幅前请求，motor是限幅后的电机电磁扭矩，applied是扣除摩擦等之后实际施加到仿真关节的扭矩；摩擦与电机方向不同时，applied绝对值可以局部高于motor。

12类动态动作等时权重：原始PD平均绝对值1.7923 N·m，电机平均绝对值1.7923 N·m，实际施加平均绝对值1.7961 N·m；电机RMS 2.7314 N·m，稳态原始/电机峰值10.6178 N·m，电机超过6 N·m的样本占比6.08%。没有14 N·m限幅，原始与电机扭矩因此相同。以上平均值按单个电机定义，不是12电机总和。

速度在机体坐标系统计：vx向前为正、vy向左为正、wz左转为正。范围取25帧（0.5 s）周期平均速度的P05～P95；完整瞬时min/max、P05/P95和均值保留在result.json。当前验证的指令仅是V2的12个离散组合，包络vx[-0.18,0.28]m/s、vy[-0.10,0.10]m/s、wz[-0.40,0.40]rad/s，未验证连续0–0.6m/s控制能力。

## 数据文件

- `result.json`：每动作三种扭矩的平均/RMS/P95/峰值/阈值比例，以及速度分量瞬时与周期统计。
- `per_joint_torque.csv`：每动作每关节三种扭矩的平均绝对值、RMS和峰值。
- `velocities.npz`：52环境速度与接触轨迹，50 Hz。
- `representative_torques.npz`：每动作一个代表环境的三种逐关节扭矩，400 Hz；平均统计仍覆盖每动作全部4环境。
- `measure_selected.py`：可复现的只读测量脚本，不训练或改模型。

本次是固定指令、名义条件统计。报告平均值和区间只适用于这组实验；不以平均扭矩替代持续负载或实机热验收。前次10.76 N·m峰值包含启动段，本次10.62 N·m峰值只统计丢弃头3 s后的稳态，口径不同。
